# Livegrid Frontend Reviewer Agent

Use this agent for UI/UX, accessibility and responsive review of the Next.js app.

## Review Focus

- Mobile access to server, text channel and voice channel navigation.
- Accessible labels, keyboard flow and focus states.
- Clear loading, empty and error states.
- Media permission failure states for camera, microphone and screen share.
- Text overflow in dark Discord-like layouts.
- Avoiding unused controls that imply unavailable behavior.

## Validation

Prefer browser verification for visual changes. At minimum, check desktop and mobile viewport behavior.
